- **Zero Real-Time Stream Latency Impact**: Anomaly explanation calculations are performed dynamically on-demand, strictly outside the synchronous WebSocket/SSE streaming loop.
- **Non-Clinical Framing**: Reconstruction errors are strictly labeled as model sequence deviations relative to learned normal patterns, NOT autonomous medical diagnoses or clinical causation.

## 4. Input Sequence Contract

The Autoencoder operates on a 30-step temporal window containing 6 normalized vital sign features:

$$\text{Input Shape}: (1, 30, 6)$$

### Standardized Vital Sign Ordering (`VITAL_COLUMNS`):
1. `heart_rate` (bpm)
2. `spo2` (%)
3. `respiratory_rate` (breaths/min)
4. `temperature` (°C)
5. `systolic_bp` (mmHg)
6. `diastolic_bp` (mmHg)

---

## 5. Preprocessing & Scaling Isolation

Raw vital sign telemetry sequences are scaled using the authoritative `scaler.pkl`:

$$S = \text{scaler.transform}(X_{\text{raw}}) \in \mathbb{R}^{30 \times 6}$$

This guarantees that feature scales (e.g., Heart Rate: 100–180 vs Temperature: 36–38) are normalized prior to computing reconstruction error distances.

---

## 6. Mathematical Reconstruction Error Formulation

Given scaled input sequence $S \in \mathbb{R}^{30 \times 6}$ and Autoencoder reconstructed output $\hat{S} = f_{\text{AE}}(S) \in \mathbb{R}^{30 \times 6}$:

$$\text{Squared Error Matrix } E_{i, j} = (S_{i, j} - \hat{S}_{i, j})^2 \quad \text{for } i \in [0..29], j \in [0..5]$$

### Overall Mean Squared Error (MSE):
$$\text{ae\_mse} = \frac{1}{30 \times 6} \sum_{i=0}^{29} \sum_{j=0}^{5} E_{i, j}$$

---

## 7. Score Invariance Guarantee

To ensure **zero score drift** between real-time risk predictions (`fusion.py`) and on-demand explanations (`autoencoder_explainer.py`), the explainer uses the exact same pseudo-probability conversion formula:

$$\text{ae\_anomaly\_score} = \text{clip}\left( 0.5 \times \frac{\text{ae\_mse}}{\text{ae\_threshold}}, 0.0, 1.0 \right)$$

- If $\text{ae\_mse} == \text{ae\_threshold}$, the score is exactly `0.5000`.
- If $\text{ae\_mse} > \text{ae\_threshold}$, `is_anomalous = True`.

---

## 8. Per-Feature Reconstruction Error Breakdown

The overall MSE is decomposed across each of the 6 individual vital sign dimensions over the 30-step window:

$$\text{MSE}_j = \frac{1}{30} \sum_{i=0}^{29} E_{i, j} \quad \text{for } j \in [0..5]$$

---

## 9. Percentage Contribution Formulation

The relative percentage contribution $P_j$ of each vital sign to the total sequence reconstruction error is calculated as:

$$P_j = \left( \frac{\text{MSE}_j}{\sum_{k=0}^{5} \text{MSE}_k} \right) \times 100\%$$

$$\sum_{j=0}^{5} P_j = 100.0\%$$

---

## 10. Time-Step Error Trace Formulation

To allow dashboard visualization of error trends over time, the MSE is computed for each time step $i \in [0..29]$ across all 6 vital signs:

$$\text{MSE}_i = \frac{1}{6} \sum_{j=0}^{5} E_{i, j}$$

If $\text{MSE}_i > \text{ae\_threshold}$, the step is flagged with `exceeds_threshold = True`.

---

## 11. Unscaled Physical Residual Formulation

For clinical interpretability, the latest scaled reading $S_{29}$ and reconstructed reading $\hat{S}_{29}$ are inverse-transformed into physical clinical units using `scaler.inverse_transform`:

$$V_{29} = \text{scaler.inverse\_transform}(S_{29})$$
$$\hat{V}_{29} = \text{scaler.inverse\_transform}(\hat{S}_{29})$$
$$\text{latest\_absolute\_residual}_j = |V_{29, j} - \hat{V}_{29, j}|$$

---

- `AutoencoderAnomalyExplainer` class encapsulates model loading, preprocessing, error matrix calculation, and physical residual formatting.
